# Country source ledger

Official authority sources behind every statutory figure or requirement the
platform stores. Sales pages never scatter these links; a figure is only as
good as its source row here. Each row carries the date it was last checked
and the date by which it must be re-verified before it may back a quotation
(90 days unless the authority publishes a change sooner).

Reviewed: 2026-08-29 · Re-verify by: 2026-11-27 · Reviewer: owner (from the
seven-country research, 29 Aug 2026).

## Reference exchange rate

The research snapshot used USD 1 = BDT 123.0707 (Bangladesh Bank reference
rate, 27 Aug 2026): https://www.bb.org.bd/en/index.php/econdata/rfrexrate.
This is a research snapshot, never a conversion rate for a quotation — live
quotes require a dated FX snapshot with provider and expiry (see the FX
requirements in `docs/SEVEN_COUNTRY_PLAN.md`).
